🧪 Type-Safe Core

Ensure printer profile models and raw filament structures conform to automated JSON schemas. Never worry about configuration drift between Rust and integrations.

📐 Geometry & Path Checkers

Detect non-manifold edges, bounds violations, and unsupported overhang normals on STL models. Run static coordinate and thermal limits audits on G-code paths.

🔒 WASM-Sandboxed Plugins

Write validation rules in Rust and run them dynamically in a hermetic WebAssembly sandbox with no socket or filesystem access. Fast, compiler-free, and safe.

🛠 Adapter Conformance SDK

Exposes automated conformance verification testing harnesses to ensure third-party connectivity clients implement states and commands cleanly.

📡 Axum REST microservice

Condition-built HTTP REST server protected by bearer token middleware. Perfect for web interfaces, slicers, or newsroom workflow integrations.

🤖 Model Context Protocol

Expose validation and inspection capabilities to LLMs and agentic development assistants over standard JSON-RPC 2.0 stdin/stdout transport.
